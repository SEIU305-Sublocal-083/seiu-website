# Our next ten days: translation review

**Sept. 12–21, 2026 · Proposed communications for SEIU 503 Sublocal 083**

This workspace brings together the English copy, sources and screenshots for 28 separate review items. Every item has its own draft PR. Spanish will be provided and checked by the translator and bilingual reviewer.

## Three channels, one consistent explanation

**Measured emails.** Sunday preparation, Monday updates, targeted voting information and the Thursday membership meeting reminder. Extra messages depend on an actual consequential change.

**An open local source for answers.** A proposed strike-information hub, focused guides, a dedicated Q&A page and dated news updates. Sources and the limits of what is known stay visible in the page.

**Coworker conversations.** A voting poster and handout support direct contact, questions and follow-through. The optional video package includes a script, captions and transcript for later production.

## Review, translate, then assemble

1. Read the English body and item-specific release conditions. Conditional announcements are separate alternatives, not verified events.
2. Add Spanish in the matching translation files, including subject lines, actions, tables, captions and visible source notes.
3. Review the final English and Spanish together. Refresh desktop and mobile screenshots of the actual rendered pages.
4. Merge completed item PRs into the translation integration branch. Keep the integration PR to `main` in draft until publication is separately authorized and the production changes are ready.

No website updates, redirects, countdowns, email deliveries or schedules are activated here. The screenshots show rendered HTML. There is no AI-generated artwork in the package.

## Sources and scope

The proposed communications cadence is an editorial recommendation. Each item carries the public references supporting its factual statements, dated attribution for union proposal summaries and clear notes where an authoritative answer is still needed. Draft PRs do not settle voting logistics, benefits eligibility, a strike start date or the result of negotiations.

The repository's publishing configuration was checked Sept. 12: GitHub Pages uses `main`. This separate review branch is for preparation and translation. See the [repository](https://github.com/SEIU305-Sublocal-083/seiu-website) and the workspace README for the review process.
